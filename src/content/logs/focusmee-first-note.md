# 先把自己的声音放进来

博客搭起来以后，最重要的一步不是继续看模板有多完整，而是尽快放进第一篇真正属于自己的内容。  
当页面里开始出现真实的语气、真实的记录和真实的名字，这个站点才会慢慢从“项目”变成“自己的地方”。

这篇文章先作为新的示例格式文章保留下来，后面你可以直接照着它继续写，也可以把其中的段落替换成你真正想发布的内容。

## 这篇文章可以当成什么

- 一篇正式发布的开场文章
- 后续写作时可直接复制的模板
- 检查首页、归档页、详情页展示效果的测试内容

## 后续可以继续写的方向

- 记录做博客、做项目、做实验时留下的过程
- 写一些短一点但有个人气味的日常观察
- 把零散想法慢慢整理成系列文章

> 先写下来，比先写得完美更重要。

## 一个常见的 Markdown 片段

```ts
const author = "Focusmee";
const publishedAt = "2026-05-02";

console.log(`${author} published a new post on ${publishedAt}.`);
```

## 给后面的自己留个小提纲

如果你以后想继续沿用这套格式，通常只需要改这些字段：

- `title`：文章标题
- `description`：列表页和 SEO 描述
- `pubDate` / `updatedDate`：发布时间和更新时间
- `category`：栏目分类，比如 `notes`、`lab`、`garden`
- `tags`：文章标签
- `mood`：页面氛围标签

接下来就可以继续替换掉其余示例文章了，让首页出现更多真正属于你的内容。
